## 开源项目

### Crystal.Avalonia
Avalonia 应用的轻量基础设施层：模块化架构、依赖注入、View/ViewModel 注册，AOT 友好，可与任意 MVVM 框架配合使用。
- 仓库: https://github.com/0use-TE/Crystal.Avalonia
- 文档: https://0use.net/Crystal.Avalonia/
- 标签: Avalonia, C#, NuGet, MIT
- GitHub Stars: 37

### GOZA.Dock
Avalonia 轻量停靠布局库，通过 Grid + DockRegion + DockSplitter 组合面板，支持桌面与 WebAssembly 演示。
- 仓库: https://github.com/0use-TE/GOZA.Dock
- 文档: https://0use.net/GOZA.Dock/
- 标签: Avalonia, Dock, WASM, MIT
- GitHub Stars: 16

### DotKernel
轻量级、Native AOT 友好的 .NET AI 内核：属性注册插件 / 提示词 / 过滤器，流式调用与工具审批管线，适合 Avalonia（桌面 + WASM）等裁剪友好场景，可作为 Semantic Kernel 的更简替代。
- 仓库: https://github.com/0use-TE/DotKernel
- 文档: https://0use.net/DotKernel/
- 标签: Avalonia, AI, AOT, NuGet, MIT
- GitHub Stars: 0

### Blazor.GoldenLayout
GoldenLayout.js 的 Blazor 封装，在 Blazor 项目中实现可拖拽、IDE 风格的分栏布局，支持声明式与代码配置。
- 仓库: https://github.com/0use-TE/Blazor.GoldenLayout
- 文档: https://0use.net/Blazor.GoldenLayout/
- 标签: Blazor, GoldenLayout, NuGet, MIT
- GitHub Stars: 8

### OpenCopy
Windows 便携工具：在禁止粘贴的网页或软件中，通过模拟键盘输入将剪贴板内容逐字打入目标窗口，支持自定义全局快捷键。
- 仓库: https://github.com/0use-TE/OpenCopy
- 标签: Windows, .NET, 工具, MIT
- GitHub Stars: 6

### GameCollections
游戏合集与相关资源整理，持续更新中。
- 仓库: https://gitee.com/ouse-TE/GameCollections
- 标签: 游戏, 合集
